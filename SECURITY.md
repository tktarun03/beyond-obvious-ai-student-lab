# Security and safe examples

This is an educational repository. The latest `main` is the only maintenance target;
there are no production support or response-time commitments.

Do not publicly post credentials, exploitable private deployment details, real student
records, payment data or employer source code. All learning fixtures should be synthetic.

For a vulnerability, use GitHub's **Report a vulnerability** option on this repository's
Security page if available. If private reporting is unavailable, ask the maintainer for
a private reporting channel in a neutral issue without disclosing exploit details.
For ordinary non-sensitive bugs, use the bug-report issue template.

Include the affected commit, impact, smallest synthetic reproduction and proposed fix.
Mock AI, in-memory storage and development authentication are learning tools. Do not
expose them as a production service for real users. See [deployment notes](docs/deployment/README.md).
