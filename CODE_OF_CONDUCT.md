# Community conduct

Help people learn. Be respectful across experience levels, languages and backgrounds.
Give specific feedback about the work, welcome corrections and assume good faith.
Disagreement is welcome; harassment, discrimination, threats, spam and sharing someone
else's private information are not.

Maintainers may edit or remove harmful content, close disruptive threads, and restrict
participation when needed. Responses should be proportionate to the behavior and its impact.

For a public conduct concern, flag the relevant GitHub content using GitHub's reporting
controls. If private details are involved, do not post them publicly; ask the maintainer
through their [GitHub profile](https://github.com/tktarun03) for a suitable private channel.
No response time is promised. This policy applies to this repository's issues, pull
requests and other spaces explicitly managed by this project.
